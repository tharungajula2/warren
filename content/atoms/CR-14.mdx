### Core mechanism

| Component | Required statement | Why it matters |
| :--- | :--- | :--- |
| Unit | Obligor, facility or homogeneous pool | Changes what can default |
| Event | Regulatory default, internal default or other defined target | Changes the outcome being predicted |
| Horizon | One year, 12 months, lifetime or another period | Changes probability mechanically |
| Observation date | Information available at prediction time | Prevents hindsight and leakage |
| Calibration basis | Mapping from score/grade to probability | Turns ranking into a probability estimate |

PD is not a declaration that a named borrower “will default”. It is a probability assigned before the outcome is known. Across repeated comparable populations, realised default frequencies should be consistent with well-calibrated probabilities within sampling and cyclical variation.

### Flow

```text
Defined unit + default event + horizon + observation date
    ↓
Score / rating / model estimate
    ↓
Calibration
    ↓
PD
```

### Flow

```text
Upstream:   Default definition · Observation date · Borrower/pool information · Score/rating
This:       Estimate and calibrate probability over stated horizon
Downstream: Pricing · Expected loss · Rating grades · Capital · Monitoring
```

### Formula

For a population observed at time `t`:

`PD_h = P(default during horizon h | information available at t)`

Horizon ↑ → cumulative probability of at least one default event generally ↑, all else equal. A one-year PD cannot be substituted mechanically for a lifetime probability.

### Permanent rule

No PD is interpretable without its unit, default definition, horizon and observation date.

### Never confuse [PD] and [Credit score]

**PD** — a calibrated probability of a specified future default event.

---
**Credit score** — a ranking or predictive output that need not itself be a probability.

### Permanent trap

Multiplying a raw score by LGD and EAD because the score “looks like a probability” creates a loss number with no valid probabilistic interpretation.

### Jurisdiction variants

**No delta in probability mathematics.** Regulatory frameworks can prescribe different default definitions, parameter floors, horizons and calibration standards; those rules change the parameter specification, not what probability means.
