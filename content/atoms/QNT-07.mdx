**Sampling bias:** A sample differs from the true population by design. In credit, a notorious case is “only current customers”: if a bank studies default rates using only customers who renewed their credit cards, it misses those who defaulted or left, underestimating risk. CASRAI warns that bias doesn’t shrink with more data – it leads precisely wrong estimates.

**Selection bias:** When the sample is chosen by outcome. For example, analyzing PD using only approved loans ignores applicants who were denied (who might be higher risk). This underestimates risk because we selected out lower-scoring individuals. Another example: surveying customers about repaying loans will naturally exclude those already delinquent or defaulted – giving an overly rosy repayment picture.

**Survivorship bias:** A type of sampling bias where only “survivors” are seen. For instance, if a study of corporate bond defaults only includes companies still listed, it misses those that defaulted or delisted. In retail credit: if we only analyze auto loans that have not been repossessed, we ignore those lost deals, again biasing PD down. CASRAI’s classic example: looking only at airplanes that returned (survivors) misleads reinforcement strategy. Similarly, analyzing only ongoing loans ignores those that “didn’t survive” to be included.

**Avoidance:** Always define a clear population: e.g. “all loans originated in 2018, tracking until 2021, including those closed by default, pay-off, or charge-off.” Use full origination data, not just current books. If data is truncated (e.g. only current borrowers), acknowledge bias and adjust (maybe via weight or external default statistics). Regulators (e.g. RBI IRB) expect PD models to account for these biases in historical data.

<Rule label="PERMANENT RULE">
Always include all relevant cases in your sample, especially failures. Missing defaulters or rejects biases any risk estimate. Double-check that your data frame contains both “survivors” and “non-survivors” from a cohort.
</Rule>

<Trap label="PERMANENT TRAP">
Using only successfully repaid loans to model performance. This creates survivorship bias: only the “winners” are analyzed, making the portfolio look safer than it is.
</Trap>

<NeverConfuse a="Survivorship bias" b="Selection bias">
**Survivorship bias** — only survivors of a process are seen (e.g. only extant accounts).
---
**Selection bias** — systematic inclusion/exclusion during data collection (e.g. excluding denied applicants).
</NeverConfuse>

<Rule label="NO DELTA">
**No delta.** Data representativeness is a universal modeling principle. However, some jurisdictions explicitly emphasize these biases: e.g. the ECB’s IRB guidelines caution against using internal data that exclude defaulted obligors.
</Rule>
