### Core mechanism

| LGD driver | Effect on net recovery |
| :--- | :--- |
| Borrower post-default payments | Increase recovery |
| Collateral sale proceeds | Increase recovery after priority and costs |
| Guarantee proceeds | Increase recovery if guarantee is enforceable and guarantor performs |
| Legal / collection / maintenance costs | Reduce recovery |
| Delay to recovery | Reduces present value |
| Seniority and prior claims | Determine how recovery value is shared |
| Downturn conditions | Can reduce collateral prices and recovery capacity together |

A simple `1 − recovery rate` relationship is valid only when recovery rate and LGD use the same exposure base, cash-flow perimeter, costs and discounting convention.

### Flow

```text
Default → Gross recoveries
    ↓
Subtract workout costs
    ↓
Discount to default date
    ↓
Net recovery / EAD → Recovery rate
    ↓
LGD = 1 − recovery rate
```

### Where it sits

```text
Upstream:   Default · EAD · Security/guarantee rights · Workout cash flows
This:       Collect gross recoveries → subtract costs → discount → compare with EAD
Downstream: Expected loss · Pricing · Capital parameters · Workout benchmarking
```

### Formula

```text
`LGD = (EAD − PV(net recoveries)) / EAD`

`Recovery rate = PV(net recoveries) / EAD`

Under aligned definitions: `LGD = 1 − recovery rate`.

Recovery delay ↑ or workout costs ↑ → PV(net recoveries) ↓ → LGD ↑.
```

### Permanent rule

Measure LGD from the default event using a consistent exposure base and economically complete recovery cash flows.

### Never confuse [Collateral value] and [LGD]

**Collateral value** — one potential source of recovery, subject to legal rights, priority, sale value, time and costs.

---

**LGD** — total economic loss severity conditional on default across all recovery sources and costs.

### Permanent trap

`LGD = 1 − collateral value / current balance` ignores pre-default drawings, borrower payments, guarantor proceeds, senior claims, costs, timing and collateral-value stress.

### Jurisdiction variants

**No delta in the economic mechanism.** Prudential frameworks differ in recognised collateral, supervisory or internal LGDs, downturn treatment, floors and discounting rules.

<Recall
  q="Why does a delayed recovery increase economic LGD?"
  a="Its present value at the default date is lower."
/>

<Recall
  q="Can a fully collateralised loan still have positive LGD?"
  a="Yes. Sale discounts, priority, costs, delays and value declines can create loss."
/>

<Recall
  q="What must match before using `LGD = 1 − recovery rate`?"
  a="Exposure base, cash-flow perimeter, costs, timing and discounting convention."
