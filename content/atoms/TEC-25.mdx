### Core mechanism

Assume `history` contains account snapshots and has already been enriched with `customer_id`. `risk_history` contains effective changes in customer risk grade:

```python
import pandas as pd

history = history.sort_values(["customer_id", "reporting_date"])
risk_history = risk_history.sort_values(["customer_id", "valid_from"])

matched = pd.merge_asof(
    history,
    risk_history,
    left_on="reporting_date",
    right_on="valid_from",
    by="customer_id",
    direction="backward",
    allow_exact_matches=True,
)
```

`direction="backward"` means the matched `valid_from` must be at or before the reporting date. A forward direction would introduce information that becomes effective later.

After matching, assert the temporal condition rather than trusting the call:

```python
valid = (
    matched["valid_from"].isna()
    | matched["valid_from"].le(matched["reporting_date"])
)
assert valid.all()
```

If `risk_history` also has `valid_to`, test that the reporting date is before the end of the interval. `merge_asof` chooses a nearest eligible start record; it does not by itself prove that effective-date intervals are non-overlapping or still valid.

Sorting requirements matter. Both DataFrames must be ordered consistently for the as-of key, and grouping with `by` keeps different customers from matching each other's histories.

Exact-date equality and as-of matching solve different problems. Use ordinary `merge` when both tables are keyed by the same reporting date; use `merge_asof` when one table records changes that occur irregularly through time.

### Never confuse [Exact-date merge] and [As-of merge]

**Exact-date merge** - requires equal date keys on both sides.

---

**As-of merge** - matches the nearest eligible effective record according to time direction and grouping keys.

### Permanent rule

Use backward matching for information known as of the observation date, then assert that no matched effective date lies in the future.

### Permanent trap

Using the nearest record without specifying direction. "Nearest" can be a future record and silently leak hindsight into historical analysis.
