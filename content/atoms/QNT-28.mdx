### Core mechanism

As the cutoff moves, recall is the same quantity as sensitivity, while precision asks how concentrated actual defaults are among flagged cases. Plotting precision against recall therefore shows the trade between capturing more defaults and diluting the flagged pool with non-defaults.

| Metric view | Denominator emphasis | Imbalance behavior |
| :--- | :--- | :--- |
| ROC | Actual defaults and actual non-defaults separately | Can remain visually strong with huge non-default population |
| Precision-recall | Predicted positives and actual defaults | Directly exposes low positive predictive value |
| PR baseline | Event prevalence | Falls as defaults become rarer |

### Permanent rule

When the event is rare, report a metric that makes the false-positive burden visible; ROC alone can hide how thin the default concentration is among flagged borrowers.

### Never confuse [ROC-AUC] and [PR-AUC]

**ROC-AUC** - summarizes true-positive versus false-positive-rate ranking across cutoffs.

---

**PR-AUC** - summarizes precision versus recall and therefore changes materially with event prevalence.

### Permanent trap

Comparing PR-AUC across two portfolios with very different default prevalence as if the numbers were directly portable. The baseline precision itself changes with prevalence.

### Jurisdiction variants

No delta. Precision-recall mathematics is universal.

<Recall
  q="Why does low default prevalence directly depress precision?"
  a="Even a modest false-positive rate applied to a very large non-default population can create many false positives relative to the small number of captured defaults."
/>

<Recall
  q="What is the random-ranking baseline for precision?"
  a="It is approximately the event prevalence, because a random flagged sample contains defaults at the same rate as the overall population."
/>

<Recall
  q="Why might ROC-AUC remain unchanged while operational precision changes?"
  a="Ranking between the two classes can be unchanged while the portfolio's class prevalence shifts, and precision depends on that prevalence."
/>
