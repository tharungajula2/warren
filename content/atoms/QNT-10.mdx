### Core mechanism

```text
Define null and alternative
    ↓
Choose test statistic before seeing the result
    ↓
Compute statistic from credit sample
    ↓
Map statistic to p-value under null assumptions
    ↓
Compare with significance level
    ↓
Interpret together with effect size and power
```

| Quantity | Meaning | Common credit mistake |
| :--- | :--- | :--- |
| Significance level | Long-run false-rejection tolerance under the null | Chosen after seeing results |
| p-value | Probability under the null of data at least this extreme | Read as probability the null is true |
| Effect size | Magnitude of the observed difference | Ignored when large n makes tiny effects significant |
| Power | Probability of detecting a specified real effect | Ignored when sparse defaults make tests weak |

### Where it sits

```text
Upstream:   Sampling distribution · Standard error · Null assumptions
This:       Test statistic · p-value · Power · Effect size
Downstream: Calibration tests · Drift comparison · Challenger comparison
```

### Formula

```text
Generic test statistic = estimated difference / standard error of that difference
```

### Permanent rule

Statistical significance answers whether random sampling variation is a plausible explanation under the null; it does not answer whether the difference matters economically or operationally.

### Never confuse [p-value] and [Probability the null is true]

**p-value** - probability, assuming the null, of observing a result at least as extreme as the one obtained.

---

**Probability the null is true** - not supplied by an ordinary frequentist p-value.

### Permanent trap

Treating "not significant" as proof of equality. A low-power test with few defaults may fail to reject large but poorly estimated differences.

### Jurisdiction variants

No delta. Hypothesis-testing mathematics is universal.

<Recall
  q="What does a p-value of 0.03 mean in a test of unchanged portfolio default rate?"
  a="If the null of no change and the test assumptions were correct, data at least this extreme would occur about 3 percent of the time; it does not mean there is a 97 percent probability that the rate changed."
/>

<Recall
  q="Why should effect size accompany a p-value?"
  a="Very large samples can make tiny, immaterial differences statistically significant, while effect size shows the magnitude that the business actually experienced."
/>

<Recall
  q="Why does sparse default data reduce power?"
  a="Fewer events increase uncertainty, making it harder for a test statistic to separate a real change from sampling noise."
/>
