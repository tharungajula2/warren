### Core mechanism

| Quantity | Scope | What it can answer | What it cannot answer |
| :--- | :--- | :--- | :--- |
| Split/gain importance | Global | Which variables trees used to improve fit | Direction for one borrower |
| Permutation importance | Global | How performance falls when a feature is disrupted | Causal effect of changing the feature |
| Mean absolute SHAP | Global summary | Average size of local attributions | Direct causal importance |
| SHAP value | Local | Contribution to one model output relative to baseline | What would happen under real-world intervention |

```text
Model + borrower + background reference
    ↓
Baseline model output
    ↓
Allocate prediction difference across features
    ↓
Feature contributions add back to model output
```

The attribution is conditional on the fitted model and the treatment of missing or unknown feature combinations. When predictors are strongly correlated, distributing shared information between them is inherently delicate.

### Where it sits

```text
Upstream:   Fitted tree model · Correlated predictors · Borrower features
This:       Global importance · Local SHAP attribution
Downstream: Model interpretation · Stability analysis · Challenger comparison
```

### Formula

```text
Model output for borrower = baseline output + sum over features of SHAP contribution
```

### Permanent rule

An explanation method explains the model's calculation, not the world's causal mechanism.

### Never confuse [Feature importance] and [Feature attribution]

**Feature importance** - aggregate measure of how much a variable matters to model behavior or performance.

---

**Feature attribution** - allocation of a particular prediction relative to a baseline across input features.

### Permanent trap

Saying "income caused the prediction to fall" because its SHAP value is negative. SHAP states how the model used income relative to its reference, not what would happen if the borrower's income were externally changed.

### Jurisdiction variants

No delta. Importance and SHAP mathematics are universal.

<Recall
  q="Why can two correlated predictors divide importance unpredictably?"
  a="They carry overlapping information, so the model or explanation method must allocate shared predictive signal between variables that are partly substitutable."
/>

<Recall
  q="What does the SHAP additivity property guarantee?"
  a="On the explained model-output scale, the baseline plus all feature contributions reconstructs that borrower's model output."
/>

<Recall
  q="Why does changing the SHAP background data matter?"
  a="It changes the reference prediction and the feature combinations against which contributions are evaluated, so attribution values can change even when the fitted model does not."
/>
