### Core mechanism

```text
Borrower predictors
    ↓
Linear predictor
    ↓
Fitted continuous outcome
    ↓
Residual = observed outcome - fitted outcome
    ↓
Choose coefficients that minimize squared residuals
```

| Object | Meaning in a lending regression |
| :--- | :--- |
| Intercept | Baseline fitted level when predictors are zero on their defined scales |
| Coefficient | Change in fitted outcome for a one-unit predictor increase, holding other included predictors fixed |
| Fitted value | Model's conditional mean estimate |
| Residual | Part of the observed outcome not captured by the fitted value |
| Least squares | Criterion minimizing total squared residual size |

For a continuous target, this can be useful. For Y equal to 0 or 1, however, a straight line has no natural probability boundary and the conditional error variance depends on the probability level.

### Where it sits

```text
Upstream:   Correlation · Sampling uncertainty · Continuous outcomes
This:       Linear predictor · Least squares · Residuals
Downstream: Logistic regression · VIF · Regularisation
```

### Formula

```text
Fitted Y = beta0 + beta1 x X1 + beta2 x X2 + ... + betak x Xk
Residual = observed Y - fitted Y
Least-squares objective = sum over cases of residual x residual
```

### Permanent rule

A linear predictor is a useful building block; ordinary least squares is not automatically a valid probability model.

### Never confuse [Linear predictor] and [Linear probability model]

**Linear predictor** - a weighted sum of inputs that can sit inside many models.

---

**Linear probability model** - directly treats that weighted sum as a probability for a binary outcome, allowing values below 0 or above 1.

### Permanent trap

Interpreting an OLS fitted value of 1.08 or -0.06 as a usable default probability. The straight-line model does not enforce probability bounds.

### Jurisdiction variants

No delta. Linear-regression mathematics is universal.

<Recall
  q="What does least squares minimize?"
  a="It chooses coefficients to minimize the sum of squared residuals, so large fitting errors receive greater penalty than small ones."
/>

<Recall
  q="Why is a straight line unsatisfactory for a binary default flag?"
  a="Its fitted values are unbounded and can fall below 0 or above 1, while binary error variance changes with the underlying event probability."
/>

<Recall
  q="Why does this atom make logistic regression natural?"
  a="The useful linear predictor can be retained while a link function maps it to a valid 0-to-1 probability and a binary likelihood replaces ordinary least squares."
