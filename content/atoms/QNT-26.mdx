### Core mechanism

```text
Sort observations by model score
    ↓
Build cumulative share of defaults across the score axis
    ↓
Build cumulative share of non-defaults across the same axis
    ↓
Measure separation at each score
    ↓
KS = largest absolute separation
```

| KS feature | Meaning |
| :--- | :--- |
| Uses cumulative distributions | Compares the whole score ordering up to each point |
| Maximum gap | Focuses on the single strongest separation point |
| Threshold location | Score where cumulative separation peaks |
| Sample dependence | Thin defaults can make the empirical maximum noisy |

KS is related to discrimination but is not identical to AUC. AUC integrates ranking behavior across the ROC curve; KS keeps only the largest difference between the two cumulative class distributions.

### Where it sits

```text
Upstream:   Score ordering · Default/non-default distributions · AUC
This:       Empirical CDF separation · Maximum KS gap
Downstream: Threshold analysis · Drift monitoring · Challenger comparison
```

### Formula

```text
KS = maximum over score cutoffs of absolute value of [ cumulative default share - cumulative non-default share ]
```

### Permanent rule

KS summarizes the largest observed separation, not the entire discrimination curve and not probability calibration.

### Never confuse [KS statistic] and [Operational cutoff]

**KS statistic** - maximum class-distribution separation observed across all score cutoffs.

---

**Operational cutoff** - business decision threshold chosen for lending action; it need not equal the score at maximum KS.

### Permanent trap

Treating the maximum-KS score as automatically optimal for approval. Business costs, capacity, risk appetite and class prevalence can make another operating cutoff preferable even when KS peaks elsewhere.

### Jurisdiction variants

No delta. KS mathematics is universal; MRM owns governed limits and escalation.

<Recall
  q="What exactly is maximized when KS is computed for a score?"
  a="The absolute difference between the cumulative default and cumulative non-default shares over all possible score cutoffs."
/>

<Recall
  q="Why can KS be unstable in a low-default segment?"
  a="Each default moves the empirical default cumulative distribution by a relatively large step, so the location and size of the maximum gap can change materially with a few events."
/>

<Recall
  q="How does KS differ conceptually from AUC?"
  a="KS keeps the single largest separation point, whereas AUC aggregates ranking performance across the full range of cutoffs."
/>
