### Core mechanism

| Quantity | Credit interpretation |
| :--- | :--- |
| Event time | Time from defined start to default |
| Censoring time | Time observation stops without recorded default |
| Survival function | Probability the borrower remains event-free beyond time t |
| Hazard | Instantaneous event intensity at t conditional on survival to t |
| Cumulative incidence | Probability an event has occurred by a horizon under the stated event setup |

```text
Origination or observation start
    ↓
Borrower remains non-default
    ↓
At each time: survive or experience event
    ↓
Default observed → event time known
Observation ends first → right-censored
```

A censored borrower still contributes information: the borrower is known to have survived event-free up to the censoring time. Survival methods use that partial information instead of pretending the borrower completed the entire horizon.

### Where it sits

```text
Upstream:   Event definition · Censoring · Seasoning
This:       Survival function · Hazard · Time to event
Downstream: Lifetime risk curves · Vintage comparison · Macro-conditioned hazard
```

### Formula

```text
Survival function S(t) = probability that event time is greater than t
Cumulative event probability by t = 1 - S(t)
Discrete hazard at t = probability of event at t given survival just before t
```

### Permanent rule

Censoring is information about how long an account survived, not evidence that it was a non-default for every future horizon.

### Never confuse [Hazard] and [Cumulative default probability]

**Hazard** - conditional near-time event intensity among borrowers that have survived so far.

---

**Cumulative default probability** - probability the event has occurred by a stated horizon.

### Permanent trap

Reading a falling hazard as falling cumulative default probability. Cumulative event probability can continue to rise even when the instantaneous hazard declines.

### Jurisdiction variants

No delta. Survival-analysis mathematics is universal.

<Recall
  q="What useful information does a right-censored loan still provide?"
  a="It establishes that the loan survived without the event up to its censoring time, which survival methods can include in estimation."
/>

<Recall
  q="Why can survival analysis be preferable to a fixed binary label for immature vintages?"
  a="It uses unequal observed follow-up times explicitly rather than discarding incomplete cases or mislabelling them as full-horizon non-defaults."
/>

<Recall
  q="How are survival probability and cumulative event probability related in a single-event setup?"
  a="Cumulative event probability by time t is one minus the probability of surviving event-free beyond t."
