### Core mechanism

| Condition | Action |
| :--- | :--- |
| Risk adequately captured | No overlay |
| New risk outside model boundary | Quantify residual impact |
| Structural break weakens calibration | Temporary adjustment + remediation |
| Same risk already enters scenario PD/LGD/EAD | Do not count again |
| Model repaired or risk disappears | Reduce or remove overlay |

### Flow

```text
Core model output
    ↓
Specific omitted risk / limitation
    ↓
Material evidence?
    ├─ No → no PMA
    └─ Yes
         ↓
Quantify residual effect
         ↓
Challenge and approval
         ↓
Final ECL
         ↓
Exit when model or risk changes
```

### Where it sits

```text
Upstream:   Core ECL model · Emerging risk · Model limitations
This:       PMA · Management overlay
Downstream: Final allowance · Validation · Disclosure
```

### Ownership

| Role | Responsibility |
| :--- | :--- |
| Model / finance owners | Identify limitation; quantify adjustment |
| Management | Approve rationale and amount |
| Risk / validation | Challenge method and double-counting |
| Audit committee / board where required | Oversee material judgement |
| Assurance | Test evidence, controls and reporting |

### Permanent rule

Every overlay needs a named residual risk, evidence, quantification method, owner and exit condition.

### Never confuse [Model recalibration] and [Post-model adjustment]

**Model recalibration** — changes the model so it better reflects risk.

---

**Post-model adjustment** — sits outside the model because a specific residual limitation remains.

### Permanent trap

A permanent unexplained percentage added to ECL is not prudent judgement. It is an unvalidated parallel model.

### Jurisdiction variants

#### IN (RBI)
RBI’s Ind AS guidance for NBFCs requires governed, documented management overlays, including audit-committee approval. RBI’s bank ECL framework from 1 April 2027 also addresses model limitations and PMAs.

#### UK (PRA)
PRA thematic work in 2025 emphasised model boundaries, evolving risks, PMA governance and reducing adjustments as models improve.

#### EU (EBA)
EBA guidance requires sound governance; adjustments must remain consistent with unbiased accounting measurement.

#### US (Federal Reserve / FDIC / OCC / NCUA)
CECL allows judgement and qualitative adjustments, but the allowance process must be documented, supported and validated.

  q="What must exist before an overlay?"
  a="A specific material risk or model limitation not adequately captured."

<Recall

<Recall
