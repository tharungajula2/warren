### Core mechanism

| Sample | Permitted use | Why it exists |
| :--- | :--- | :--- |
| Training | Fit coefficients, trees and transformations | Learn model parameters |
| Validation | Choose hyperparameters, bins, features or stopping point | Compare development choices |
| Test | Final performance estimate after choices are frozen | Measure selection-adjusted generalisation |
| Out-of-time | Later observation period | Test temporal robustness and regime change |

```text
Earlier time
Training → Validation → Freeze model choices → Test or OOT
Later time
```

Repeatedly checking test results and returning to model development contaminates the test set even if no row is literally added to training. Human selection has extracted information from it.

Random splitting can still be useful for some iid questions, but credit data contain vintages, repeated customers and macro regimes. The split must prevent the same underlying information from leaking across partitions and should resemble deployment.

### Where it sits

```text
Upstream:   Vintage structure · Model fitting · Tuning choices
This:       Train · Validation · Test · OOT
Downstream: Leakage analysis · Performance metrics · Model comparison
```

### Formula

```text
Generalisation gap = training performance - untouched evaluation performance
```

### Permanent rule

Every modelling choice consumes information from the data used to make that choice. Final evaluation must come from data not consumed by fitting or selection.

### Never confuse [Validation set] and [Test set]

**Validation set** - used to choose among candidate modelling decisions.

---

**Test set** - held back until those decisions are frozen, then used for final performance estimation.

### Permanent trap

Calling a dataset "test" after it has been consulted dozens of times to tune features, bins or hyperparameters. Functionally it has become validation data.

### Jurisdiction variants

No delta. Sample-splitting logic is statistical. MRM owns governance over validation execution and findings, not these mechanics.
