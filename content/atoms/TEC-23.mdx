Or summarizing a loan tape into segments:
```python
summary = df.groupby('Segment').agg(&#123;'Outstanding':'sum', 'LoanID':'count'&#125;)
```

This avoids explicit Python loops. Even custom functions can often be expressed as vectorized NumPy functions or pandas aggregations.

In short: treat DataFrames like in-memory tables and use built-in operations. This is akin to using `SUM` in SQL vs iterating rows in application code.

### Permanent rule

Always prefer pandas/NumPy vectorized methods (`.sum()`, `.mean()`, etc.) over manual Python loops for column-wise operations.

### Permanent trap

Using `df.apply()` with a Python function on rows can be as slow as loops. Test performance; often a group-by or built-in aggregate is much faster.

### Never confuse

**Vectorized operation** — an operation applied to entire array/column at once (fast, in C).

---

**Python loop or apply** — iterates in Python for each row (slow).
