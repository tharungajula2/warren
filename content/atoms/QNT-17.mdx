### Core mechanism

```text
Training borrowers
    ↓
Choose split that improves node purity
    ↓
Repeat within child nodes
    ↓
Terminal leaves produce predictions
    ↓
Deep single tree: low training error, high variance
    ↓
Bootstrap many trees + random feature subsets
    ↓
Average predictions to reduce variance
```

| Mechanism | What it contributes |
| :--- | :--- |
| Recursive split | Captures thresholds and interactions without a linear form |
| Depth control | Limits how finely noise can be partitioned |
| Bootstrap sample | Gives each tree a different training view |
| Feature subsampling | Reduces correlation among trees |
| Averaging | Cancels part of the trees' idiosyncratic variance |
| Out-of-bag cases | Provide internal predictions from trees that did not train on that case |

### Where it sits

```text

```

### Formula

```text
Forest probability = (sum of tree probabilities) / number of trees
```

### Permanent rule

The forest gains stability by averaging imperfect, deliberately different trees; it does not become reliable merely because it contains many trees.

### Never confuse [Bagging] and [Boosting]

**Bagging** - trains models largely in parallel on resampled data and averages them to reduce variance.

---

**Boosting** - trains models sequentially so later learners focus on errors left by the current ensemble.

### Permanent trap

Calling a random forest immune to overfitting. Deep trees, leakage, unstable data and poor time splits can still produce an ensemble that generalises badly.
