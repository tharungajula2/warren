### Core mechanism

| Element | Owns | Test of quality |
| :--- | :--- | :--- |
| Rating criteria | How an obligor is assigned | Consistent use of relevant risk drivers |
| Master scale | Ordered risk states | Clear monotonic deterioration from strong to weak |
| Grade PD | Probability attached to grade/pool | Calibration consistent with observed/default definition |
| Override | Governed expert departure | Reason, authority and performance tracked |
| Migration | Movement between grades | Stable state definitions through time |
| Default grade | Terminal/default state for the relevant system | Aligned with governed default definition |

A transition matrix counts or estimates movement from each starting grade to each ending grade over a fixed interval, including default. Migration separates a static stock of weak borrowers from a portfolio actively deteriorating toward those grades.

### Flow

```text
Borrower information → Rating assessment / score → Grade
    ↓
Master-scale position → Grade PD
    ↓
New information → Upgrade / downgrade / default
```

### Where it sits

Upstream:   Borrower information · Rating philosophy · PD calibration
This:       Assign grade → map to master scale → observe migration through time
Downstream: Limits · Pricing · Monitoring · PD validation · Capital · Early warning

### Ownership

| Role | Responsibility |
| :--- | :--- |
| Produces | Rating model/process assigns and documents the grade |
| Approves | Credit authority or rating governance confirms assignment/override where required |
| Consumes | Underwriting, portfolio monitoring, pricing, capital and reporting |
| Challenges | Independent credit risk, model validation and audit test scale performance |

### Permanent rule

A grade must retain a stable, documented meaning if historical default and migration statistics are to remain comparable.

### Never confuse [Rating migration] and [PD recalibration]

**Rating migration** — the obligor moves from one risk grade to another.

---

**PD recalibration** — the probability mapped to a grade or score changes; the grade label can remain unchanged.

### Permanent trap

Changing grade criteria and then analysing the old and new labels as one continuous transition history produces false migration statistics.

### Jurisdiction variants

**No delta in the concept.** Regulatory frameworks differ in rating-system granularity, approval, floors, use tests and validation requirements.

<Recall
  q="What gives a rating grade meaning?"
  a="Its documented assignment criteria, position in the master scale and calibrated risk/default relationship."
/>

<Recall
  q="What does a transition matrix preserve that a rating snapshot loses?"
  a="The direction and frequency of movement between grades through time."
/>

<Recall
  q="Can grade PD change without rating migration?"
  a="Yes. Recalibration can alter the probability mapped to an unchanged grade."
/>
