For example, a bank might designate one system or database as the golden source for the exchange rate used in all risk reports, or the official customer master record. All downstream processes then draw from that gold record. This prevents situations where different departments have conflicting values for the same metric. Building a golden source requires strong data governance: clear ownership of the data field, defined quality rules, and processes to update the source whenever new information arrives.

The golden source concept is vital under BCBS 239 Principle 2 (Data Architecture): it supports reconciliation and ensures “a single, authoritative source” for each risk metric. Without it, banks often hit the trap of “multiple authorities” – e.g. one system reporting Value-at-Risk one way, another giving a different number. A common rule is that only the golden source can feed regulators; any other calculation must reconcile back to it.

Golden source is sometimes synonymous with “source of truth” or “master dataset.” It is not static: it is updated continuously to reflect the latest true data. Achieving a golden source typically involves integrating data pipelines and may use technologies like master data management (MDM) tools. The permanent expectation is that *every key data field* has one golden source designated, so that accuracy and consistency are maintained.

```text
          +-------------------------+
          | Golden Source Database  |
          +-------------------------+
           ^       ^        ^     ^
           |       |        |     |
     +-----+     +---+    +---+  +---+
     | CRM |     | Trade   | Market| ...
     | Sys |     | Sys     | Data  |
     +-----+     +---+    +---+  +---+
```

### Permanent rule

For each key data element, the bank must designate one authoritative source and use it consistently.

### Permanent trap

Allowing multiple “masters” for the same data field (e.g. one report using Core banking data, another using Risk system) causes conflicts and undermines trust.

### Never confuse

**Golden source** — The official, authoritative dataset for a piece of information.

---

**Data lake** — A repository of raw data. A data lake is not by itself an authoritative source unless governance ensures it contains only validated data.

### Jurisdiction variants

**No delta.** The concept of a single authoritative source is best practice worldwide; regulators expect banks to avoid conflicting data sources.
