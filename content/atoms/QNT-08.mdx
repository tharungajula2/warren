### Core mechanism

| Distribution | Credit anchor | Key condition |
| :--- | :--- | :--- |
| Bernoulli | One loan defaults or does not | One binary trial with event probability p |
| Binomial | Number of defaults among n similar loans | Fixed n, common p, independent trials |
| Poisson | Approximate rare-event count | Many opportunities, small event probability, weak dependence |
| Normal approximation | Aggregated estimates or sums | Enough independent or weakly dependent contributions |
| Right-skewed positive distribution | Exposure sizes or recovery amounts | Quantity bounded below with long upper tail |

```text
Single loan event → Bernoulli
Many similar independent loan events → Binomial count
Rare events with large n and small p → Poisson approximation
Large weakly dependent aggregate → Normal approximation may emerge
```

Credit portfolios often violate independence because borrowers share macro drivers. That is exactly why a distribution that works for independent coin-flip intuition can understate clustered default outcomes during stress.

### Where it sits

```text
Upstream:   Event prevalence · Cohort definition · Dependence
This:       Event distributions · Count approximations
Downstream: Sampling uncertainty · Regression likelihoods · Portfolio inference
```

### Formula

```text
Expected binomial defaults = n x p
Binomial variance = n x p x (1 - p)
Poisson rate lambda = n x p
Poisson variance = lambda
```

### Permanent rule

Use a distribution because its assumptions match the credit process, not because its formula is familiar.

### Never confuse [Individual event distribution] and [Portfolio aggregate distribution]

**Individual event distribution** - describes one loan or one event process.

---

**Portfolio aggregate distribution** - describes a sum or count whose shape also depends on concentration and dependence across loans.

### Permanent trap

Applying an independent binomial model to a portfolio where defaults cluster through common economic conditions. The count variance can then be much larger than the independent model implies.

### Jurisdiction variants

No delta. Distributional mathematics is universal.

<Recall
  q="When can Poisson approximate a binomial default count?"
  a="When the portfolio has many comparable opportunities, each with a small event probability, and dependence is weak enough that rare events are approximately independent."
