The key directives (2022) state that banks/NBFCs must not use agents to harass borrowers. No coercion is allowed: no making calls before 8 am or after 7 pm, no abuse/insults, no shame-tactics. Agents must have clear ID/name tags; they must follow written guidelines. The regulated entity (bank or NBFC) remains liable for any breach by its agents.

Prior RBI codes (2006 &amp; 2010) prohibited many misbehaviors (e.g. third-party visits to workplaces for small debts). The 2022 circular specifically supplements these with updated instructions under the outsourcing framework, emphasizing that violations can lead to supervisory action.

This is consumer protection in collections: borrowers have recourse to the bank’s grievance cell for any agent mis-step, and ultimately to the Ombudsman. Banks must train and monitor their agents (even if they are third-party contractors).

### Permanent rule

Banks/NBFCs must ensure recovery agents comply with RBI’s conduct rules: no threat, no personal harassment, call only between 8am-7pm, respectful behavior. ID cards are mandatory.

### Permanent trap

Assuming recovery can be “any means necessary.” RBI’s explicit code bans intimidation (Verbal/physical harassment, false claims, repeated late-hour calls). Non-compliance by agents is deemed violation by the lender.

### Never confuse

**Recovery Agent** — hired agent or third-party who collects overdue loans. (Subject to RBI’s code of conduct.)
**Debt Collector** — similar role; RBI’s rules apply equivalently, unlike unregulated field agents for non-financial debts.

### Jurisdiction variants

**IN** — RBI’s Code for recovery agents is detailed and mandatory (2016/2022). Other countries regulate debt collectors (e.g. US Fair Debt Collection Practices Act) differently, but India’s code is specific to banking debts.
