### Core mechanism

| Rule component | Example |
| :--- | :--- |
| Population | All active corporate-loan records at reporting cut-off |
| Dimension | Completeness |
| Condition | Counterparty identifier is populated |
| Expected result | Every in-scope record carries an approved identifier |
| Threshold / tolerance | Governed level based on materiality and use |
| Evidence | Exception population, pass rate, run timestamp, rule version |
| Action | Investigate breach, assess report impact, remediate and escalate |

```text
Definition and use requirement
    ↓
Design executable DQ rule
    ↓
Run against defined population
    ↓
Measure result against tolerance
    ↓
Pass → retain evidence
Breach → assess impact → issue management
```

Thresholds are risk decisions. Zero tolerance may be appropriate for a mandatory identifier in a small critical population; a different control may allow a documented tolerance where errors are immaterial and separately contained. The bank should not invent a Basel percentage and label it universal.

### Where it sits

```text
Upstream:   DQ dimensions · CDEs · Metadata · Consumer requirements
This:       Rules, thresholds and monitoring
Downstream: Exception populations · Reconciliation · Issue management · Reporting controls
```

### Ownership

| Role | Contribution |
| :--- | :--- |
| Owner | Approves required quality and tolerance |
| Steward | Maintains rule inventory and monitors results |
| Producer | Fixes production causes within its process |
| Consumer | Assesses use and reporting impact |
| Challenge | Tests rule design, coverage and evidence |

### Permanent rule

A quality metric without a defined population and governed threshold cannot support a defensible control conclusion.

### Permanent trap

Tuning thresholds until dashboards turn green. Tolerances should reflect risk appetite and use, not the current defect rate.

### Jurisdiction variants

**No delta.** The control mechanic is universal; regulators or return taxonomies may impose specific validation rules for particular submissions.
