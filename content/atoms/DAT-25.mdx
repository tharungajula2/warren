### Core mechanism

```text
Applicable return and reference date
    ↓
Freeze instructions, taxonomy or form version
    ↓
Source governed populations
    ↓
Transform, classify and aggregate
    ↓
Run validations and reconciliations
    ↓
Resolve or approve exceptions and adjustments
    ↓
Reviewer sign-off
    ↓
Submission-ready return and evidence pack
```

| Production control | Evidence |
| :--- | :--- |
| Version control | Applicable instructions, form or taxonomy at the reference date |
| Completeness | Population counts and source coverage |
| Transformation | Approved mappings and job versions |
| Reconciliation | Source-to-return and risk-to-finance controls where relevant |
| Adjustments | Reason, owner, approver and reversal or remediation path |
| Exceptions | Impact assessment and disposition |
| Review | Named preparer / checker or equivalent control |

PD, LGD, EAD, RWA, ECL staging, LCR and NSFR may feed returns, but their calculation mechanics belong to CR, CAP, IMP and TLM. DAT owns whether the resulting data reaches the return accurately and traceably.

### Where it sits

```text
Upstream:   Governed sources · Mapping · Reconciliation · Extract validation
This:       Recurring regulatory return production
Downstream: Submission · Attestation · Restatement · Supervisory use
```

### Permanent rule

Every submitted field should be reproducible for its reference date from governed source data, approved transformation logic and retained control evidence.

### Permanent trap

Using the prior-period return as the primary source for the current return. Prior returns are useful for analytical comparison, not as a substitute for rebuilding from governed current-period data.

### Jurisdiction variants

**No delta in the production logic.** The forms, taxonomies, deadlines, validation rules and submission channels differ and are owned by the jurisdiction atoms.

<Recall
  q="Why must the applicable form or taxonomy version be frozen for each cycle?"
  a="Reporting requirements change over time; reproducibility depends on proving which instructions and technical version governed the reference date."
/>

<Recall
  q="What is the proper role of prior-period comparison?"
  a="It is an analytical control for unexpected movement, not the authoritative source of current-period values."
/>
