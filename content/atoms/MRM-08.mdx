### Core mechanism

```text
Selection / development
    ↓
Developer testing
    ↓
Independent validation
    ↓
Approval
    ↓
Deployment and use
    ↓
Ongoing monitoring
    ↓
Change / recalibration / redevelopment
    ↓
Revalidation and reapproval where required
    ↓
Retirement
```

| Gate | Minimum decision |
| :--- | :--- |
| Development complete | Is the evidence pack sufficient for independent challenge? |
| Validation complete | Is the model reliable enough for its intended use, with known limitations? |
| Approval | Is residual model risk acceptable and use authorised? |
| Deployment | Does production reproduce the approved model? |
| Monitoring | Does evidence still support continued use? |
| Change | Does the change reopen validation or approval? |
| Retirement | Can use cease without breaking dependencies or records? |

Lifecycle controls are recursive. A material change can return an active model to development, validation and approval rather than allowing an informal production patch.

### Where it sits

```text
Upstream:   Inventory · Tiering · Governance policy
This:       Lifecycle states and gates
Downstream: Development · Validation · Approval · Monitoring · Change · Retirement
```

### Ownership

| Role | Responsibility |
| :--- | :--- |
| Model owner | Coordinates the model through lifecycle stages |
| Developer | Produces development and change evidence |
| Validation / MRM | Independently challenges relevant stages |
| Approval authority | Authorises use and material changes |
| Business user | Operates only within approved conditions |

### Permanent rule

A lifecycle stage creates evidence; a gate creates authority. Evidence from one stage is not authority to skip the next.

### Never confuse [Validation] and [Approval]

**Validation** - independent assessment of reliability, limitations and fitness for intended use.

---

**Approval** - governance decision to accept residual risk and authorise specified use, possibly with conditions.

### Permanent trap

Treating "live" as the final state. Production use begins a new control phase in which monitoring, issue management, change and eventual retirement remain governed.

### Jurisdiction variants

No delta. The cited regimes use different language and degrees of prescription, but the lifecycle logic of development, challenge, approval, use, monitoring, change and exit is common.

<Recall
