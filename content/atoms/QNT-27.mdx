### Core mechanism

| Actual / predicted | Predict default | Predict non-default |
| :--- | :--- | :--- |
| Actual default | True positive | False negative |
| Actual non-default | False positive | True negative |

```text
Move cutoff toward more borrowers classified default
    ↓
True positives usually ↑
    ↓
False positives usually ↑
    ↓
Sensitivity ↑ while specificity tends to ↓
```

No threshold metric is intrinsically best. The useful metric depends on which denominator answers the business question: all actual defaults, all actual non-defaults, or all predicted defaults.

### Where it sits

```text
Upstream:   Model scores · Chosen cutoff · Actual outcomes
This:       Confusion matrix · Sensitivity · Specificity · Precision
Downstream: Precision-recall curve · Cutoff economics · Monitoring
```

### Formula

```text
Sensitivity = true positives / (true positives + false negatives)
Specificity = true negatives / (true negatives + false positives)
Precision = true positives / (true positives + false positives)
False-positive rate = 1 - specificity
F1 = 2 x precision x sensitivity / (precision + sensitivity)
```

### Permanent rule

Every threshold metric must be read with its denominator. Two metrics using the same four counts can answer entirely different questions.

### Never confuse [Sensitivity] and [Precision]

**Sensitivity** - among actual defaults, how many the cutoff captures.

---

**Precision** - among cases flagged as default, how many actually default.

### Permanent trap

Optimizing a cutoff on F1 and calling it economically optimal. F1 assigns an implicit balance to precision and sensitivity but contains no loan margin, loss severity or operational cost.

### Jurisdiction variants

No delta. Confusion-matrix mathematics is universal; MRM owns governance around performance thresholds.
