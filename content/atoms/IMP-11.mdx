### Formula

```text
ECL = sum over t [Marginal PD_t × EAD_t × LGD_t × DF_t]

Marginal PD_t = probability that default occurs in period t and has not occurred earlier.

EAD_t = exposure expected at default in period t.

LGD_t = expected loss severity conditional on default in period t.

DF_t = discount factor bringing the period-t loss to the reporting date.

t = each future period inside the applicable ECL horizon.
```

### Core mechanism

| Stage / framework | Default periods entering the engine |
| :--- | :--- |
| IFRS 9 Stage 1 | Defaults possible within next 12 months |
| IFRS 9 Stage 2 | Defaults possible over remaining relevant life |
| IFRS 9 Stage 3 | Lifetime expected cash shortfalls on credit-impaired asset |
| CECL | Expected losses over applicable contractual term |
| RBI bank ECL from 1 Apr 2027 | Stage-dependent 12-month / lifetime structure |

### Flow

```text
Stage / framework
    ↓
Default horizon
    ↓
Marginal PD by period
    ↓
EAD and LGD at each possible default date
    ↓
Discount each loss
    ↓
Sum expected losses
    ↓
Scenario weighting / adjustments
    ↓
Final ECL
```

### Where it sits

```text
Upstream:   Stage · PD · LGD · EAD · Discount factors
This:       Period-by-period ECL aggregation
Downstream: Scenario ECL · Allowance · Validation
```

### Permanent rule

All model components must describe the same exposure, default definition, timing basis and economic scenario.

### Never confuse [ECL formula] and [Accounting definition]

```text
**ECL formula** — a modelling architecture.

---
**Accounting definition** — the loss quantity the framework requires the model to estimate.
```

### Permanent trap

Mixing a lifetime PD with current EAD and one-year LGD, or mixing conditional and unconditional default probabilities, can create a number that looks precise but has no coherent probabilistic meaning.

### Jurisdiction variants

#### IN (RBI)
Current commercial-bank IRACP does not require this engine. RBI’s framework from 1 April 2027 uses a general PD/LGD/EAD-style approach within its ECL requirements.

#### UK (UKEB)
IFRS 9 does not prescribe PD/LGD/EAD as the only permissible technique.

#### EU (European Commission / EBA)
Same accounting position as IFRS 9; EBA guidance focuses on sound implementation rather than one mandatory model form.

#### US (FASB)
CECL is method-neutral: PD/LGD is permitted but not mandatory.
