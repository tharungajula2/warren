### Core mechanism

| Tool | Mechanism | Credit use |
| :--- | :--- | :--- |
| VIF | Regress one predictor on the others | Diagnose redundant linear information |
| Ridge | Penalize squared coefficient size | Stabilize many correlated signals |
| Lasso | Penalize absolute coefficient size | Shrink some coefficients exactly to zero |
| Elastic net | Combine both penalties | Handle correlated groups while allowing sparsity |

High collinearity does not necessarily destroy predictions; it destroys confidence that any one coefficient represents a separately identified effect. Small changes in sample composition can then move signs and magnitudes sharply.

### Where it sits

```text
Upstream:   Linear predictor · Correlated lending variables
This:       VIF · Ridge · Lasso · Bias-variance trade
Downstream: Stable model fitting · Feature selection · Generalisation
```

### Formula

```text
VIF for Xj = 1 / (1 - R-squared from regressing Xj on the other predictors)
Ridge objective = fitting loss + lambda x sum over coefficients of coefficient squared
Lasso objective = fitting loss + lambda x sum over coefficients of absolute coefficient
```

### Permanent rule

Stable prediction and stable coefficients are different objectives. Collinearity can leave the first acceptable while making the second unreliable.

### Never confuse [Multicollinearity] and [Correlation with the target]

**Multicollinearity** - predictors explain one another.

---

**Target correlation** - a predictor is associated with the outcome. A variable can be highly predictive and still be highly collinear with another predictor.

### Permanent trap

Using a universal VIF cutoff as if it were a law of nature. VIF is a diagnostic; materiality depends on whether coefficient stability, inference or only prediction is the modelling objective.

### Jurisdiction variants

No delta. VIF and regularisation mathematics are universal.

<Recall
  q="What happens to VIF as one predictor becomes almost perfectly explained by the others?"
  a="The denominator approaches zero, so VIF becomes very large and the coefficient's sampling variance is strongly inflated."
/>

<Recall
  q="How do ridge and lasso differ under strong penalty?"
  a="Ridge shrinks coefficients toward zero but generally retains them; lasso can set some exactly to zero and therefore acts as a selection mechanism."
/>

<Recall
  q="Why can lasso be unstable with highly correlated predictors?"
  a="Several variables may contain nearly interchangeable signal, so small data changes can make lasso retain one and discard another without a meaningful economic distinction."
/>
