**Normal distribution:** Symmetric bell-curve, defined by mean (μ) and variance (σ²). In credit risk, many aggregated quantities (e.g. average credit score across many independent borrowers) tend toward normal by the Central Limit Theorem (CLT) (see QNT-03). Internal models like the Vasicek IRB model assume a normal latent variable for asset returns.

**Lognormal distribution:** A variable is lognormal if its logarithm is normal. It is right-skewed (long tail on right). Credit risk example: firm asset values or portfolio losses are often modeled as lognormal. The Vasicek/Merton framework assumes firm asset value follows lognormal growth, so log(asset) is normal. Many individual loss severities (e.g. loss given default) are positive and skewed, fitting a lognormal shape.

**Binomial distribution:** Models the number of defaults in *n* independent loans with default probability *p*. If defaults are independent, defaults ~ Binomial(n,p). Its mean np and variance np(1-p). A single loan’s annual loss (either full loss or none) is Bernoulli (a 0-1 loss), so a portfolio loss is the sum of Bernoullis, a binomial. FRM notes: “the probability distribution for the loss from the ith loan is... binomial”. Binomial is key for small portfolio loss estimation or mapping small default events.

**Poisson distribution:** Models count of rare independent events over fixed exposure. If the chance of default is small (p ≪ 1) and number of loans large, Binomial(n,p) ≈ Poisson(λ=np). For portfolios with many small exposures and low default rate, default counts ≈ Poisson. Poisson also arises for counting loan prepayments or rare credit events. It has one parameter λ (mean=variance).

Using the correct distribution is crucial for risk metrics: e.g. mis-specifying default count as normal (when events are rare) underestimates tail risk. Each distribution’s parameters should be estimated from data or expert priors, and used consistently in simulations or VaR calculations.

```text
Loan defaults:     aggregate risk:
+---------+       +---------+
|Bernoulli|       | Binomial|
| (0 or 1)|  ---&gt; |(n,p)    |
+---------+       +---------+
      |                 |
      v                 v
 Defaults count  ~ Binomial
 (rare defaults, large n)
             ≈ Poisson
```

### Permanent rule

Each distribution’s assumptions must match the credit context (e.g. non-negative, skewed, independent events). Using a normal model for highly skewed or discrete data leads to wrong estimates.

### Permanent trap

Treating an inherently skewed quantity (like loan loss amounts) as normally distributed can underestimate extreme losses. For example, assuming symmetric losses when actual losses (e.g. severe defaults) follow a long-tailed lognormal can understate required provisions.

### Never confuse

**Binomial distribution** — count of successes (e.g. defaults) in a fixed number of trials (loans) with success probability *p*.
---
**Poisson distribution** — count of independent events (e.g. defaults) over fixed exposure/time when events are rare. Poisson can approximate binomial for large *n* and small *p* (np=λ).

### Jurisdiction variants

**No delta.** Probability distributions and their shapes are mathematical truths. Specific regulatory models (e.g. Basel IRB) may use these distributions (e.g. Vasicek’s normal-based model), but the underlying math is universal.
