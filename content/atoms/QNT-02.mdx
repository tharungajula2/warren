### Core mechanism

CR owns default as a governed credit status. QNT owns the statistical construction of an analyzable outcome from that status across time.

| Case at observation date | Status after horizon | Statistical treatment |
| :--- | :--- | :--- |
| Default occurs within full horizon | Event observed | Label 1 |
| Full horizon completes without default | Non-event observed | Label 0 |
| Account has not yet completed horizon | Outcome incomplete | Right-censored or excluded under a governed rule |
| Account exits for a competing reason | Outcome path interrupted | Requires explicit competing-risk or censoring treatment |

```text
Observation date
    ↓
Feature snapshot fixed
    ↓
Performance window opens
    ↓
Default inside window? → Yes → Event observed
    ↓ No
Window fully completed? → Yes → Non-event observed
    ↓ No
Censored observation
```

### Where it sits

```text
Upstream:   Default status · Observation date · Feature timing
This:       Label · Performance horizon · Censoring
Downstream: Vintage design · Rare-event estimation · Survival analysis
```

### Formula

```text
Binary label Y = 1 if event occurs within horizon, otherwise 0 only when the horizon is fully observed
Observed follow-up time = minimum(event time, censoring time)
```

### Permanent rule

A non-default label requires enough observation time to know that default did not occur inside the defined horizon.

### Never confuse [Non-default] and [Censored]

**Non-default** - the required performance window completed without the event.

---

**Censored** - observation ended before the full event path became known.

### Permanent trap

Labelling every recently originated account as non-default because no default has happened yet. That converts lack of observation into evidence of good performance and biases event rates downward.

### Jurisdiction variants

No delta. The statistical treatment of incomplete observation is universal; the underlying default definition may be governed elsewhere.

<Recall
  q="Why does a newly originated loan usually not qualify immediately as a clean non-default observation for a one-year model?"
  a="Its one-year performance window has not finished, so absence of default so far is incomplete information rather than a fully observed non-event."
/>

<Recall
  q="What statistical problem appears when observation ends before the borrower defaults or completes the horizon?"
  a="The record is censored, meaning the available data reveal only that the event had not happened up to the censoring time."
/>
