### Core mechanism

| Validation layer | What is challenged |
| :--- | :--- |
| Conceptual soundness | Accounting objective and portfolio economics |
| Data | Completeness, accuracy, representativeness |
| Implementation | Code, transformations, mappings, aggregation |
| PD | Discrimination, calibration, term structure, realised defaults |
| LGD | Recovery amount, timing, costs, realised severity |
| EAD | Drawdown, amortisation, exposure-at-default behaviour |
| Staging | Migration timing, SICR triggers, rebuttals, cure |
| Scenario / overlay | Sensitivity, weights, omitted risk, double-counting |
| Governance | Approval, limitations, change control, challenge |

### Flow

```text
Model design
    ↓
Independent conceptual review
    ↓
Implementation verification
    ↓
Performance testing
    ↓
Backtesting
    ↓
Staging challenge
    ↓
Findings
    ↓
Remediate · recalibrate · redevelop · monitor
```

### Where it sits

```text
Upstream:   ECL models · Staging rules · Data · Overlays
This:       Validation · Backtesting · Independent challenge
Downstream: Model approval · Remediation · Allowance confidence
```

### Ownership

| Role | Produces / challenges |
| :--- | :--- |
| Model owner | Model, data, documentation |
| Independent validation | Conceptual and quantitative challenge |
| Finance / credit risk | Use and interpretation |
| Internal audit | Framework and control assurance |
| Board / committees | Oversight of material models and findings |

### Permanent rule

Validation tests the model against its intended use, not merely whether the developer’s calculation can be reproduced.

### Never confuse [Backtesting] and [Validation]

**Backtesting** — compares predictions with realised outcomes.

---

**Validation** — broader independent challenge of design, implementation, performance and use.

### Permanent trap

A plausible aggregate allowance can hide offsetting PD, LGD, EAD or staging errors. “Total ECL looks reasonable” is not validation.

### Jurisdiction variants

#### IN (RBI)
RBI’s bank ECL framework from 1 April 2027 establishes model governance, independent validation and post-implementation backtesting.

#### UK (PRA)
PRA’s 2025 thematic feedback emphasises monitoring, validation and model operating boundaries.

#### EU (EBA)
EBA/GL/2017/06 sets expectations for sound ECL methodology and governance.

#### US (Federal Reserve / FDIC / OCC / NCUA)
Interagency guidance expects periodic validation independent of credit approval and allowance estimation, including conceptual soundness, monitoring and output analysis.
