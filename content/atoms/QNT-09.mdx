### Core mechanism

For a large, reasonably homogeneous sample, a default-rate estimator can often use a normal approximation. When events are rare or counts are small, exact binomial or carefully chosen alternative intervals are preferable because symmetric approximations can extend below zero or behave poorly near the boundary.

| Driver | Effect on uncertainty |
| :--- | :--- |
| More independent observations | Usually narrows standard error |
| More observed events | Improves information about event probability |
| Strong dependence | Reduces effective information relative to raw n |
| Very small p | Makes symmetric normal approximations fragile |
| Narrow segmentation | Can sharply widen intervals through sparse counts |

### Where it sits

```text
Upstream:   Event distribution · Sample size · Default prevalence
This:       Standard error · Confidence interval · Approximation
Downstream: Hypothesis testing · Calibration assessment · Model comparison
```

### Formula

```text
Estimated default rate p-hat = defaults / n
Approximate standard error = square root of [ p-hat x (1 - p-hat) / n ]
Approximate confidence interval = p-hat plus or minus critical value x standard error
```

### Permanent rule

Pair a point estimate with its uncertainty whenever finite default history matters. A difference in observed rates is not automatically a meaningful difference in underlying risk.

### Never confuse [Confidence interval] and [Probability that the parameter lies in the interval]

**Confidence interval** - a repeated-sampling procedure designed to cover the fixed parameter at a stated long-run rate.

---

**Posterior probability interval** - a Bayesian statement assigning probability to parameter values after combining prior assumptions and data.

### Permanent trap

Using a symmetric large-sample interval for a grade with almost no defaults and then treating its neat endpoints as precise evidence. Sparse-event intervals are exactly where approximation choice matters most.
