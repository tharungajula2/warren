### Core mechanism

| Test | Question |
| :--- | :--- |
| Inputs | Does it consume data, estimates, judgement or structured inputs? |
| Transformation | Does it apply statistical, mathematical, economic, financial or comparable analytical assumptions or techniques? |
| Output | Does it estimate, predict, classify, rank, optimise or inform a decision? |
| Uncertainty | Can data, assumptions or method make the output wrong even when implementation is correct? |
| Use | Does output affect business, risk, reporting, capital, customer or operational decisions? |

Model classification follows substance, not software:

```text
Simple arithmetic spreadsheet → may be a non-model tool
Spreadsheet + estimation assumptions + decision output → may be a model
Complex deterministic rule set → treatment depends on the applicable framework
```

### Where it sits

```text
Upstream:   Business process · Quantitative method · Decision tool
This:       Model classification
Downstream: Model perimeter · Inventory · Tiering · Lifecycle controls
```

### Ownership

| Role | Responsibility |
| :--- | :--- |
| Tool/model owner | Proposes classification and documents function and use |
| MRM function | Challenges boundary decisions |
| Business user | Identifies actual decision impact |
| Internal audit | Tests classification controls |

### Permanent rule

Classify the method and its use, not its technology label. "Spreadsheet", "algorithm" and "AI" do not determine model status by themselves.

### Never confuse [Model] and [Non-model tool]

**Model** - uses assumptions and analytical techniques to transform inputs into estimates or decision-relevant outputs with model uncertainty.

---

**Non-model tool** - performs deterministic processing without the model characteristics defined by the applicable framework, though it can still require strong controls.

### Permanent trap

Treating "not a model" as "not risky". A material deterministic calculator can cause major loss even when legitimately outside the model inventory.

### Jurisdiction variants

| Jurisdiction | Definition / scope | Boundary / status |
| :--- | :--- | :--- |
| US | SR 26-2: complex quantitative method using statistical/economic/financial theories on inputs for estimates. | Simple arithmetic/deterministic rules without those theories excluded. |
| UK | SS1/23: quantitative methods using statistical/economic/financial/mathematical theories, techniques and assumptions. | Broader; material complex deterministic methods outside scope may still warrant MRM controls. |
| EU | ECB Guide: CRR internal models. | No enterprise-wide definition. |
| IN | Draft: broad input-processing-output test including internal/third-party/AI/ML systems. | Draft as at August 2026; issued 24 June 2026; consultation closed 24 July 2026. |
