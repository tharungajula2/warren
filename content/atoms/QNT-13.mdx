### Core mechanism

```text
Borrower predictors
    ↓
Linear predictor z
    ↓
Map z through logistic function
    ↓
Probability p between 0 and 1
    ↓
Fit coefficients by binary likelihood
```

| Quantity | Interpretation |
| :--- | :--- |
| Probability p | Chance of event on the model's defined population and horizon |
| Odds | p divided by 1 - p |
| Log-odds | Natural log of the odds |
| beta coefficient | Additive change in log-odds per unit change in predictor |
| exp(beta) | Multiplicative change in odds per unit change in predictor |

The effect on probability is nonlinear: the same coefficient shift changes p most around the middle of the probability range and less near 0 or 1.

### Where it sits

```text
Upstream:   Linear predictor · Binary outcome · Credit variables
This:       Logit link · Odds · Binary likelihood
Downstream: Binning · WoE · Calibration · Discrimination
```

### Formula

```text
z = beta0 + beta1 x X1 + beta2 x X2 + ... + betak x Xk
odds = p / (1 - p)
log-odds = ln(odds) = z
p = 1 / (1 + exp(-z))
odds ratio for one-unit increase in Xj = exp(betaj)
```

### Permanent rule

Logistic coefficients are linear in log-odds, not in probability percentage points.

### Never confuse [Odds] and [Probability]

**Odds** - p divided by 1 - p, comparing event probability with non-event probability.

---

**Probability** - p itself, bounded from 0 to 1.

### Permanent trap

Reading beta = 0.20 as a 20 percentage-point increase in default probability. It is a 0.20 increase in log-odds; the probability change depends on the starting probability.

### Jurisdiction variants

No delta. Logistic-regression mathematics does not change by jurisdiction.

<Recall
  q="What problem does the logistic function solve that OLS on a binary default flag does not?"
  a="It maps an unbounded linear predictor into a probability strictly between 0 and 1, while fitting the binary outcome through an appropriate likelihood."
/>

<Recall
  q="What does exp(beta) represent?"
  a="It is the multiplicative change in event odds for a one-unit increase in that predictor, holding other included predictors fixed."
/>

<Recall
  q="Why can the same beta produce different probability changes for two borrowers?"
  a="Logistic regression is nonlinear on the probability scale, so the marginal change depends on each borrower's starting log-odds and probability."
/>
