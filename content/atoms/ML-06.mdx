Predictors explain each other.

Consequences:

- unstable coefficients
- large standard errors
- coefficient signs can flip
- interpretation becomes difficult

## VIF

<Formula math="\Large \displaystyle VIF_j = \frac{1}{1-R_j^2}" />

Higher VIF:

→ stronger multicollinearity.

### Solutions

- remove redundant variable
- combine variables
- PCA
- Ridge
- accept if prediction is good and inference is not priority

---

## Regression Metrics

## MAE

<Formula math="\Large \displaystyle MAE= \frac{1}{n}\sum|y-\hat y|" />

Easy interpretation.

## MSE

<Formula math="\Large \displaystyle MSE= \frac{1}{n}\sum(y-\hat y)^2" />

Punishes large errors heavily.

## RMSE

<Formula math="\Large \displaystyle RMSE=\sqrt{MSE}" />

Same units as target.

## $R^2$

<Formula math="\Large \displaystyle R^2= 1- \frac{SS_{res}}{SS_{tot}}" />

Fraction of variance explained relative to mean baseline.

### Never rely on $R^2$ alone.

## When Linear Regression Is Not Enough

Residual curve?

→ transformations / interactions / splines / tree models

Extreme values?

→ robust approaches

Highly non-linear relationship?

→ trees / boosting / ANN

Many correlated variables?

→ regularisation

## Logistic Regression

For binary target:

<Formula math="\Large \displaystyle p=P(Y=1|X)" />

Log odds:

<Formula math="\Large \displaystyle \log \left( \frac{p}{1-p} \right) = \beta_0+\beta_1x_1+\cdots+\beta_px_p" />

Probability:

<Formula math="\Large \displaystyle p= \frac{1}{1+e^{-z}}" />

where

<Formula math="\Large \displaystyle z=\beta_0+\beta_1x_1+\cdots+\beta_px_p" />

---

## Logistic Coefficient Interpretation

<Formula math="\Large \displaystyle e^{\beta_j}" />

= **odds ratio**

Example:

<Formula math="\Large \displaystyle e^{\beta_j}=1.4" />

→ one-unit increase in $x_j$ multiplies odds by **1.4**, holding others fixed.

Not:

{/* UNVERIFIED CLAIM — check primary source before publishing */}
> probability increases by 40%.

**Odds ≠ probability.**

---

## Logistic Regression Assumptions / Checks

| Check | Meaning |
|---|---|
| Binary target | basic logistic case |
| Independent observations | avoid correlated errors |
| Linear relationship with log-odds | continuous variables |
| No severe multicollinearity | coefficient stability |
| Adequate events | estimation stability |
| No complete separation | predictors cannot perfectly isolate class |

Logistic does **not** require:

- normally distributed predictors
- normally distributed residuals
- constant residual variance
