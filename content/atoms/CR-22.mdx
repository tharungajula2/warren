### Core mechanism

| Method | Groups by | Compares | Best at revealing |
| :--- | :--- | :--- | :--- |
| Vintage | Origination period | Performance at the same months-on-book | Underwriting/channel/cohort changes |
| Roll rate | Current credit state | Next-period movement to worse, same or better state | Direction and speed of delinquency |
| Snapshot | Observation date | Stock in each state today | Current composition only |

A six-month-old cohort and a three-year-old cohort have had different time to season. Comparing their cumulative defaults on the same calendar date confounds credit quality with age. Vintage curves instead align performance at month 1, month 2, month 3 and so on.

Roll rates answer a different question: of accounts now at 30–59 DPD, how many cure, stay, move to 60–89 DPD or default next period? Identical current delinquency stocks can therefore hide opposite future directions.

### Flow

```text
Vintage: Origination cohort → MOB 1 → MOB 2 → MOB 3 → … → cumulative delinquency / default
    ↓
Compare later vintages at the same months-on-book

Roll rate: Current → Early delinquency → Later delinquency → Default state
    ↓
At each step: cure / stay / worsen
```

### Where it sits

Upstream:   Origination date · Account age · DPD/default states · Observation history
This:       Cohort by vintage OR transition by state
Downstream: Early warning · Collections capacity · Forecasting · Policy review · Model validation

### Formula

Illustrative one-step roll rate:

`Roll rate(i → j) = count/exposure moving from state i to state j / starting count/exposure in state i`

The numerator and denominator must use the same population basis and interval.

### Permanent rule

Compare like with like in time: equal seasoning for vintages, and fixed start/end states and intervals for roll rates.

### Never confuse [Vintage analysis] and [Roll-rate analysis]

**Vintage analysis** — follows origination cohorts through account age.

---

**Roll-rate analysis** — follows transitions between credit or delinquency states through time.

### Permanent trap

A fast-growing young book can look safer than a mature book simply because many accounts have not existed long enough to reach default.

### Jurisdiction variants

**No delta.** These are analytical methods; local definitions determine the delinquency and default states being tracked.
