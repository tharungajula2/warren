### Core mechanism

Filter an August loan book to active positive-balance accounts:

```python
import pandas as pd

mask = (
    loans["reporting_date"].eq("2026-08-31")
    &amp; loans["status"].eq("ACTIVE")
    &amp; loans["outstanding_balance"].gt(0)
)

active = loans.loc[
    mask,
    ["account_id", "outstanding_balance", "days_past_due"]
].copy()
```

The parentheses make boolean precedence visible. The `.copy()` is useful when the filtered result will be modified independently of the source DataFrame.

Create a lending flag with label-based assignment:

```python
active["arrears_flag"] = active["days_past_due"].gt(0)
active.loc[active["days_past_due"].isna(), "arrears_flag"] = pd.NA
```

`.loc` selects by labels and boolean conditions. `.iloc` selects by integer position and is useful when the business meaning genuinely depends on position, not when the analyst merely happens to know a column is currently the fourth column.

```python
first_five = active.iloc[:5]
selected = active.loc[:, ["account_id", "outstanding_balance"]]
```

Avoid chained assignment such as filtering a DataFrame and assigning into the temporary expression in one ambiguous operation. It can produce warnings or updates that do not affect the object you thought you were changing.

Filtering cost is mostly proportional to rows and columns touched. Build masks from vectorized Series operations and select only the columns needed downstream rather than iterating row by row.

### Never confuse [loc] and [iloc]

**loc** - selects by row or column labels and accepts boolean masks aligned to those labels.

---

**iloc** - selects by integer positions, independent of the business labels stored in the index or columns.

### Permanent rule

Use `.loc` for business-labelled filtering and assignment; use `.iloc` only when positional selection is genuinely intended.

### Permanent trap

Writing chained assignment and assuming the source DataFrame changed. Work on an explicit DataFrame and assign through `.loc` or a direct column assignment.

<Recall
  q="Why build a boolean mask with explicit parentheses?"
  a="It makes the intended combination of conditions unambiguous and reduces errors when several `&` and `|` conditions are combined."
/>

<Recall
  q="When is `.iloc` appropriate in credit analysis?"
  a="When the required selection is genuinely positional, such as taking the first five displayed rows, not when a business field should be selected by name."
/>

<Recall
  q="Why call `.copy()` on a filtered portfolio that will be modified?"
  a="It creates an explicit independent object for later assignments and avoids ambiguity about whether changes should propagate to the original DataFrame."
