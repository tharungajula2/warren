### Core mechanism

To stack two monthly exception files while preserving every row, use `UNION ALL`:

```sql
SELECT account_id, reporting_date, days_past_due
FROM loan_snapshots
WHERE reporting_date = '2026-07-31'
  AND days_past_due &gt; 0
UNION ALL
SELECT account_id, reporting_date, days_past_due
FROM loan_snapshots
WHERE reporting_date = '2026-08-31'
  AND days_past_due &gt; 0;
```

`UNION` performs an additional duplicate-removal step. That may be required, but it can also hide repeated rows that should have been investigated and usually costs more than `UNION ALL` because the engine must identify duplicates.

To find July accounts absent from August, use a set difference where the SQL dialect supports it:

```sql
SELECT account_id
FROM loan_snapshots
WHERE reporting_date = '2026-07-31'
EXCEPT
SELECT account_id
FROM loan_snapshots
WHERE reporting_date = '2026-08-31';
```

A `NOT EXISTS` anti-join is a portable alternative and can preserve additional columns from the left-side population. `INTERSECT` returns rows present in both compatible sets.

Set operations compare row values in corresponding column positions. The branches must return the same number of columns with compatible data types and the same semantic meaning. Matching technical types are not enough if, for example, one branch labels `balance` in local currency and the other in base currency.

### Where it sits

```text
Upstream:   Defined populations · Compatible columns
This:       UNION ALL · UNION · INTERSECT · EXCEPT
Downstream: Population reconciliation · Change analysis · Exception files
```

### Never confuse [UNION ALL] and [UNION]

**UNION ALL** - stacks all rows, including duplicates.

---

**UNION** - stacks rows and then removes duplicates from the combined result.

### Permanent rule

Use `UNION ALL` unless duplicate removal is part of the business requirement, and make the semantic meaning of corresponding columns identical across branches.

### Permanent trap

Using `UNION` to "clean" duplicate source records. The operation can conceal a grain problem by silently removing repeated result rows.

### Jurisdiction variants

No delta. Set-operation mechanics do not vary by regulator.
