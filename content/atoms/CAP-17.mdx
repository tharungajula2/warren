### Core mechanism

```text
PD ─────┐
LGD ────┤
EAD ────┼→ supervisory risk-weight function → capital requirement → RWA
Maturity┤
        └→ prescribed correlation structure
```

| Input | Capital intuition |
| :--- | :--- |
| PD ↑ | Default tail risk generally ↑ |
| LGD ↑ | Loss severity at default ↑ |
| EAD ↑ | Amount exposed at default ↑ |
| Maturity ↑ | More time for deterioration can increase requirement |
| Correlation ↑ | More common systematic tail risk |

The mapping is nonlinear. Expected loss intuition such as PD × LGD × EAD describes a central expected amount under simplified assumptions; IRB capital adds the adverse systematic tail and regulatory calibration.

### Where it sits

```text
Upstream:   IRB permission · PD/LGD/EAD
This:       Regulatory risk-weight function
Downstream: IRB RWA · input floors · provision comparison · output floor
```

### Formula

```text
Expected loss intuition = PD × LGD × EAD

IRB capital requirement = supervisory function of PD, LGD, maturity and correlation, applied to EAD under the Basel rules

The full regulatory function is intentionally not reduced here to a memorised algebraic expression; the important object is the mapping and its governed inputs.
```

### Permanent rule

IRB capital is a tail-risk calculation using prescribed supervisory structure; it is not PD × LGD × EAD.

### Never confuse [Expected loss] and [IRB capital]

**Expected loss** — central expected credit loss.

---

**IRB capital** — prudential unexpected-loss requirement generated by the regulatory function.

### Permanent trap

Assuming a 10% increase in PD always causes a 10% increase in capital ignores the nonlinearity of the risk-weight function.

### Jurisdiction variants

No delta in the Basel mechanism. Local permission, parameter constraints and exposure eligibility determine where it can be used.
