### Formula

```text
Closing allowance = Opening allowance + allowance on new exposures + remeasurement changes + migration effects - allowance released on derecognition - write-offs + other required movements

Opening allowance = loss allowance at start of period.

Remeasurement changes = changes in expected loss without requiring a separate transaction.

Migration effects = allowance changes caused by moving between 12-month and lifetime treatment.

Write-offs = amounts removed when there is no reasonable expectation of recovery.
```

### Core mechanism

| Movement | Typical allowance effect |
| :--- | :--- |
| New Stage 1 loan | Adds initial allowance |
| Stage 1 → Stage 2 | Usually increases allowance horizon materially |
| Stage 2 → Stage 1 | Usually releases part of allowance |
| Stage 2 → Stage 3 | Remeasures lifetime loss under credit impairment |
| Repayment / derecognition | Removes related allowance |
| Better forecast / recovery | Can create impairment gain |
| Write-off | Reduces gross asset and associated allowance |

### Flow

```text
Opening allowance
    ↓
Portfolio transactions
    +
Stage migration
    +
Risk / scenario remeasurement
    +
Overlays
    -
Write-offs / derecognition
    ↓
Closing allowance
    ↓
Disclosure reconciliation and explanation
```

### Where it sits

```text
Upstream:   Staging · Models · Scenarios · Portfolio activity
This:       Allowance roll-forward · ECL disclosure
Downstream: Financial statements · Audit · Investor / supervisor review
```

### Permanent rule

A movement in allowance should be explainable by changes in exposures, credit state, assumptions or recognised losses.

### Never confuse [Allowance reconciliation] and [Model validation]

**Allowance reconciliation** — explains how the reported balance changed.

---

**Model validation** — tests whether the process producing that balance is fit for purpose.

### Permanent trap

A large unexplained “model change” or “management adjustment” line defeats the purpose of disclosure even if the arithmetic reconciliation balances.

### Jurisdiction variants

#### IN (RBI)
Current commercial-bank IRACP has its own provisioning disclosures. RBI’s ECL framework from 1 April 2027 introduces stage-based ECL reporting and related disclosures.

#### UK (UKEB)
IFRS 7 requires explanations of credit-risk-management practices, ECL assumptions and loss-allowance movements.

#### EU (European Commission / EBA)
EU-adopted IFRS 7 and IFRS 9 apply; EBA supervision overlays the accounting disclosures.

#### US (FASB)
ASC 326 requires allowance, credit-quality, past-due and other relevant credit-loss disclosures rather than IFRS 9 stage reconciliations.
