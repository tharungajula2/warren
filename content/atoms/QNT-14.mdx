Random forests apply the bootstrap-aggregation (bagging) technique to decision trees. We draw \(m\) random samples (with replacement) from the training data, train a separate tree on each sample, then combine the results. In classification (e.g. default/no default) the forest takes a majority vote; in regression (e.g. loss given default) it averages outputs. Additionally, at each split, a random forest only considers a random subset of features (e.g. \(\sqrt&#123;p&#125;\) of \(p\) total) to decide the split. This feature subsampling de-correlates the trees, further reducing variance. The ensemble is thus robust: even if some trees overfit their sample, the majority smooths out idiosyncrasies. The model requires minimal preprocessing: features of different scales or missing values are handled inherently by trees.

In a credit scoring example, we might build 100 trees on different bootstrap samples of loan records. Each tree might split on various borrower attributes. The forest’s predicted probability of default is the average of all trees’ PD outputs. This typically outperforms one tree, as shown in practice: adding more trees (up to a point) usually lowers test error. Importantly, random forests can provide a measure of *out-of-bag* error (error on samples not included in each bootstrap), which serves as an internal validation.

### Permanent rule

A random forest uses *all* trees at inference, so the final prediction is an average (regression) or majority vote (classification) of many decorrelated trees. This ensemble effect dramatically lowers variance versus one tree.

### Permanent trap

Assuming a random forest cannot overfit. In practice, if trees are too deep or features too many, forests can still overfit noise. Also, forests reduce variance but do little to correct bias: if no tree can capture an effect, the ensemble won’t either.

### Never confuse

**Random forest** — an ensemble that builds many trees on random samples (bagging) and aggregates their outputs for robustness.

---

**Gradient boosting** — an ensemble built sequentially, where each tree is trained to correct the residuals of the prior ensemble. Unlike a random forest’s parallel bagging, boosting trains trees one after another.

### Jurisdiction variants

**No delta.** Random forests are a universal statistical technique with no jurisdiction-specific differences.
