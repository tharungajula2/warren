Example: to list all unique borrower IDs from two legacy loan tables:
```sql
SELECT BorrowerID FROM Loans_Old
UNION
SELECT BorrowerID FROM Loans_New;
```
This yields each ID once. To find IDs present in both tables:
```sql
SELECT BorrowerID FROM Loans_Old
INTERSECT
SELECT BorrowerID FROM Loans_New;
```

### Permanent rule

All SELECTs combined by UNION/INTERSECT/EXCEPT must have the same number of columns and compatible types.

### Permanent trap

Forgetting that `UNION` removes duplicates; use `UNION ALL` if you need to preserve them. Also ensure column order and types match.

### Never confuse

**UNION** — appends rows from queries into one result (distinct by default).

---

**JOIN** — combines columns from tables based on a key.

### Jurisdiction variants

**No delta.** Set operations behave the same in standard SQL for all jurisdictions.
