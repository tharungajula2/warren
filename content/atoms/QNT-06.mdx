### Core mechanism

| Technique | What changes | What does not automatically change |
| :--- | :--- | :--- |
| Oversample defaults | More default rows or repeated default cases in training | Real portfolio prevalence |
| Undersample non-defaults | Fewer majority-class rows used in fitting | Real number of non-default borrowers |
| Class weights | Loss contribution per class | Observed feature values |
| Synthetic minority examples | Local feature-space representation | Historical event count |

```text
Imbalanced labelled sample
    ↓
Resample or reweight for training
    ↓
Fit ranking relationship
    ↓
Evaluate on untouched prevalence
    ↓
Correct probability scale if training prevalence was altered
```

Sampling can improve learning efficiency but can also distort estimated probabilities. A classifier trained on a 50:50 resampled dataset has seen a different class prior from a portfolio where only 2 percent default; its raw probability output therefore requires careful calibration before being read as portfolio event probability.

### Where it sits

```text
Upstream:   Rare defaults · Development sample
This:       Oversampling · Undersampling · Class weighting
Downstream: Logistic fitting · Calibration · Precision-recall
```

### Formula

```text
Weighted log loss = - sum over cases of weight x [ Y x ln(p) + (1 - Y) x ln(1 - p) ]
```

### Permanent rule

Keep an untouched evaluation sample at natural portfolio prevalence. Training balance is a modelling choice; deployment prevalence is an empirical property.

### Never confuse [Class weighting] and [Probability calibration]

**Class weighting** - changes the fitting objective so some mistakes count more.

---

**Probability calibration** - aligns predicted probabilities with observed event frequencies on the intended population.

### Permanent trap

Reporting probabilities from a heavily resampled training set as if they were automatically calibrated to the live book. Better minority-class learning does not guarantee a correct probability level.

### Jurisdiction variants

No delta. Resampling and weighting mathematics are universal.
