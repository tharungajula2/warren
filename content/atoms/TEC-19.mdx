After grouping, common aggregates include `.sum()`, `.count()`, `.mean()`, `.min()`, `.max()`. Pandas also has `.agg()` to apply multiple functions or custom ones. The result keys become the index by default (similar to GROUP BY making the group columns the new index). 

```python
grouped = df.groupby(['ProductType', 'Vintage'])
result = grouped['Balance'].sum()
```

This produces a MultiIndex Series with each (ProductType, Vintage) combination’s total balance. Use `reset_index()` if you want the keys as columns again.

<Rule label="PERMANENT RULE">
By default, grouped keys become the index of the result. Use `as_index=False` in `groupby()` or `reset_index()` afterward to turn them back into columns.
</Rule>

<Trap label="PERMANENT TRAP">
Forgetting to aggregate: `df.groupby('X')` alone does not compute anything. Also, using `apply(lambda x: ...)` is often much slower than using built-in aggregates.
</Trap>

<NeverConfuse a="groupby" b="pivot">
**groupby** — aggregates data by keys (like SQL `GROUP BY`).  
---  
**pivot** — reshapes (reorients) data without aggregating (or with separate logic). Pivot tables convert grouped results to a wide format, which is a distinct operation.
</NeverConfuse>

<Rule label="NO DELTA">
**No delta.** The split-apply-combine paradigm is language-agnostic; pandas follows it consistently.
</Rule>
